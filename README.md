# Invent a Word We Need

Entry for [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0)
on make.fun — coin one new English word and define it in a single clear
line of at most 140 characters.

## The word (93 characters)

> Mutologue (n.) — a long speech delivered to a video call before discovering you were on mute.

## Why this word

- **A real gap:** everyone who has worked a remote video call has
  delivered a careful point to a muted microphone. English had no word
  for that moment.
- **Built like English builds words:** mute + monologue, in the same
  family as monologue and dialogue, so it is sayable, spellable and
  memorable at first sight.
- **One reading is enough:** the word names the gap and the line
  explains it — no second sentence or example needed.
- **Genuinely new:** "mutologue" appears in no dictionary; the
  nearest neighbour, "multilogue", means something else entirely.

## How it runs

`main.ts` (Node 22, standard library only) writes the word and its
definition to `/output/entry.txt`. Run locally with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
